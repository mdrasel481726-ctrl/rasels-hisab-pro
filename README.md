# Rasel's Hisab Pro - Expense Tracker App

একটি সম্পূর্ণ Offline বাংলা ব্যয় ট্র্যাকিং অ্যাপ্লিকেশন।

## বৈশিষ্ট্য
- ✅ সম্পূর্ণ Offline (Internet প্রয়োজন নেই)
- ✅ আয় এবং খরচ ট্র্যাক করুন
- ✅ Custom Categories
- ✅ বিস্তারিত রিপোর্ট এবং বিশ্লেষণ
- ✅ Backup & Restore
- ✅ সুন্দর ডিজাইন
- ✅ বাংলা ভাষা সমর্থন

## প্রযুক্তিগত স্ট্যাক
- Android SDK 21+
- Kotlin
- AndroidX
- Material Design 3
- Gson (JSON processing)

## বিল্ড এবং ইনস্টল করা

```bash
./gradlew build
./gradlew installDebug
```

## Play Store এ আপলোড করার জন্য

```bash
./gradlew bundleRelease
```

এরপর Google Play Console এ `.aab` ফাইল আপলোড করুন।
